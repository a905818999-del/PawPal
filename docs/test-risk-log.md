## Risk Decisions

- No current P0 test-system gap blocks continuing M2A.
- Public release remains blocked by RISK-005 and RISK-006 until asset provenance, likeness approval, and Rourou nearest-row state approval are settled.
- Current deterministic gate is `pnpm smoke:m2a`; legacy pre-M2 `smoke:m1` semantics must not be used as the current M2A package gate.
- Manual-only risks remain for tray, general drag/multi-monitor/DPI, final visual quality beyond the WebP edge/blink repair, and SmartScreen/AV.
- Full `$test-case-system` completion is blocked by RISK-015 until the required source/case/risk schemas and per-case gate fields are repaired.
